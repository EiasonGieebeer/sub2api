# 充值、订阅与计费

## 计费方式

平台可能提供余额按量计费和订阅套餐。每次请求根据模型、输入输出量、请求类型、价格和适用倍率结算，具体以购买页面及控制台使用记录为准。管理员可按分组配置逐模型价格，并决定是否启用长上下文阶梯；Grok 分组还可能分别配置视频模型/分辨率、每千次搜索、Realtime 每分钟、TTS 每百万字符和 STT 每小时价格。只有相关功能与价格均已配置且密钥可访问时，这些能力才可用。

## 充值

在[「充值/订阅」](https://sub.fastapi.cool/purchase)页面选择「充值」标签页，输入充值金额并选择页面展示的支付方式。页面会展示支付金额、手续费、到账余额等信息；不同支付方式可能有不同手续费、最小金额、最大金额和币种。

不要向个人账户转账，也不要相信索要密码、完整 API Key、邮箱验证码或 TOTP 密钥的所谓客服。

## 订阅

在[「充值/订阅」](https://sub.fastapi.cool/purchase)页面选择「订阅」标签页，选择可用套餐并完成支付。套餐可能限制周期额度、并发、模型范围、倍率、有效期和峰值时段价格，购买前请阅读页面说明。

已购买的套餐可在[「我的订阅」](https://sub.fastapi.cool/subscriptions)查看状态、有效期、用量进度和续费入口。

## 订单

支付后可在[「我的订单」](https://sub.fastapi.cool/orders)查看订单状态。订单可能处于待支付、处理中、成功、失败、取消或过期等状态；如页面提示有待支付订单过多，请先完成或取消现有订单。

支付过程中可能跳转到二维码页、Stripe、Airwallex、支付宝或微信等支付页面，具体以当前站点配置和页面展示为准。

## 兑换码

如果你获得了兑换码，可在[「兑换码」](https://sub.fastapi.cool/redeem)输入并兑换。兑换码可能用于增加余额、并发或订阅权益，具体以兑换成功后的页面提示和账户记录为准。

## 异常扣费处理

如发现重复支付、余额未到账或明显计费异常，请保留订单号、支付时间、请求时间及相关截图，通过 `fast.api@qq.com` 联系客服。不要发送完整密钥。

退款条件和处理方式请查看[退款政策](https://sub.fastapi.cool/legal/refund)。
